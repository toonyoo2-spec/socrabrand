# 강의노트 공통 생성 규격

버전: 2026-10-04.2. 적용 대상은 앞으로 새로 생성하는 강의노트다. 기존 Drive 문서는 수정하지 않는다.

## 근거와 우선순위

기존 수작업 강의노트 20개(1–19강, 22강)를 서로 비교했다. 표지와 주요 제목의 서식은 20개 모두 동일했고, 본문은 같은 틀 안에서 수작업 편집 차이가 있었다. 가장 많이 반복된 구조를 기본 규격으로 정한다. 특정 문서의 빈 줄 수나 개별 단어의 색을 모든 강의에 복사하지 않는다.

내용과 정답은 현재 입력한 PPT가 기준이다. 문서 구조와 공통 제목은 이 규격을 적용한다. 예문 안의 정확한 강조 범위, 밑줄, 색상 대비, 부분 볼드는 현재 PPT의 문자별 서식으로 보존한다. 사용자가 승인한 편집 예외가 있으면 해당 문맥에서만 우선 적용한다.

## 공통 구조와 서식

| 요소 | 적용 규격 | 20개 문서에서 확인한 근거 |
| --- | --- | --- |
| 글꼴·본문 | Noto Sans KR, 13pt | 공통 본문 서식 |
| 표지 과정명 | 30pt, 굵기 900, #00663A | 20/20 |
| 강의 제목 | 20pt, 굵기 900, #00663A | 20/20 |
| 순서 | 표지 → 강의 제목 → Dialogues → 정답 → Key Points #1–#4 | 공통 구조 |
| Dialogues·Key Points | 13pt 볼드, #00663A, 배경 #D9EAD3 | 20/20 |
| 정답 제목 | 13pt 검정 볼드 | 20/20 |
| 핵심 표현 번호 | 검정 볼드, 배경 #DFFFC9 | 80개 중 64개 볼드, 16개 일반 |
| 핵심 표현과 대표 번역 | 초록 #38761D 볼드 | 82개 중 81개 |
| 독립 용어 제목 | 기본 검정 볼드, 배경 없음 | 용어 후보 339개 중 325개 볼드 |
| 영어 예문 | 기본 검정 일반 글씨, 해당 구간만 강조 | 예문 388개 중 386개 검정 일반 |
| 비슷한 표현 제목 | 초록 #38761D 볼드, 배경 없음 | 11개 중 9개; 나머지는 서로 다른 편집 |
| 문서 행간 | 115%, 문단 앞·뒤 0pt | 20/20에서 반복되는 본문 간격 |

독립 용어 제목과 짧은 사용 예문을 구분한다. `shake off`는 용어 제목이지만, 단어만 부분 강조된 `crisp reply` 같은 사용 예문은 일반 글씨를 유지한다. `red flag`/`green flag`처럼 의미를 구별하는 원본 색, 비교 소제목의 원본 색, 설명 속 부분 볼드는 보존한다. `용어 한국어 뜻` 형태는 `용어: 한국어 뜻`으로 정리하며, 내용·순서는 바꾸지 않는다. ‘관련 표현’, ‘의 활용형’, ‘의 여러가지 표현’은 뜻 정의가 아닌 묶음 소제목으로 구분해 원본 제목 색을 보존하고 콜론을 추가하지 않는다.

## 간격과 페이지 흐름

PPT에서 위치를 맞추려고 넣은 연속 빈 줄은 그대로 가져오지 않는다. 용어·뜻·예문·번역을 하나의 의미 묶음으로 정리한다.

- 핵심 표현과 첫 설명 사이: 빈 줄 1개.
- 새 용어 또는 새 설명 묶음 앞: 빈 줄 1개.
- 예문과 그 번역 사이: 빈 줄 없음.
- 번역 뒤 다음 예문 묶음 앞: 빈 줄 1개.
- 소제목 배지와 바로 뒤 설명 사이: 빈 줄 없음.
- 번호 #2·#3·#4 앞: 새 페이지에서 시작한다. 이전 번호의 내용을 같은 페이지에 섞지 않는다.
- 제목·용어는 뒤 설명과 함께 유지한다. Key Points #1 시작은 새 페이지이며, #2·#3·#4도 각각 새 페이지에서 시작한다. 한 표현의 설명이 한 장을 넘으면 다음 장으로 이어지되 글꼴을 축소하지 않는다. 2026-10-04 사용자 요청에 따라 기존 자연스러운 흐름 규칙을 변경했다.

웹 미리보기는 A4 용지를 페이지별로 표시하고 화면 폭에 맞춰 용지 전체를 축소한다. 긴 내용은 다음 용지로 이어지며 페이지 번호를 표시한다. 웹 미리보기에는 브라우저의 Noto Sans KR 글자 상자 높이를 고려한 행간 1.65를 사용한다. Google Docs/Word의 115%와 서로 다른 렌더링 단위다. 하이라이트가 인접 행을 가리지 않게 하면서, 저장 문서에는 위의 문서 간격을 적용한다.

## 강조 범위

같은 단어를 검색해 전부 칠하지 않는다. PPT의 문자 위치별 서식에서 해당 구간만 가져온다. 일반 제목에 예문의 하이라이트를 복사하지 않는다. 여러 강조 단어 사이의 공백은 칠하지 않는다. 문장 전체 볼드·색을 예문에 무조건 전파하지 않는다. 짧은 감탄문, 부분 볼드와 특별한 비교 색상은 원본 정보를 유지한다.

## 승인된 문맥별 편집 예외

1강 `cross paths` 예외는 사용자가 제공한 기존 문서 캡처를 기준으로 한다. 세 가지 path 정의와 해당 예문이 모두 존재하는 문맥에서만 적용한다.

- `cross paths`와 path 정의 세 줄은 검정 일반 글씨.
- `같이 해석해 볼까요?`는 검정 일반 글씨.
- `career path` 앞에 `path 활용` 배지: #00663A 배경, 흰색 일반 글씨.
- `Our paths crossed …`는 `paths`와 `crossed`만 강조. `Our`와 공백은 제외.
- 해당 묶음의 예문 앞 콜론은 제거하고, 용어·뜻 사이 콜론은 유지.

이 예외의 문구나 서식을 다른 수업에 임의로 추가하지 않는다. 새 예외는 원문과 기준 문서의 차이를 확인한 뒤 조건·처리·검증 사례를 함께 추가한다. 수작업 문서와 페이지 끝 위치까지 100% 같다고 간주하지 않는다.

## 구현과 검증

공통 규격은 `web/format.mjs`, 문맥·묶음 규칙은 `web/editorial.mjs`에서 관리한다. 웹 미리보기·Word 다운로드·Google 문서 저장은 동일한 정규화된 행을 사용한다.

22개 PPT의 전체 문장·정답·순서와 #1–#4 연결을 회귀 검증한다. 별도 테스트 폴더에서 저장한 Google 문서를 다시 읽어 글꼴·굵기·색·배경·밑줄·문단 간격을 검증한 뒤 완료 처리한다. 기존 문서와의 비교에서는 내용, 문자 서식, 문단 간격, 페이지 흐름을 분리해 평가하며 하나의 모호한 ‘전체 동일률’로 합치지 않는다.

저장은 현재 강의 버튼을 한 번 눌러 실행한다. 지정 폴더가 있으면 그 안에 저장하며, 없으면 PPT 상위 폴더의 `강의노트`를 재사용하거나 생성한다. 같은 이름의 기존 파일은 덮어쓰지 않고 링크를 표시한다. 저장 실패 원인은 저장 버튼 옆에 표시한다.
