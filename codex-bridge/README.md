# Agency → Codex 전환 검토

현재 상태: 로컬 준비 단계. 운영 DB 적용·서버 함수 배포·Claude 루틴 중지·컴퓨터 자동 실행 설치는 아직 완료되지 않았다.

사이트 입력 → 기존 Supabase에 저장 → 새 작업 대기열 → 이 Mac의 Codex CLI(ChatGPT 로그인) → 연결된 Supabase 플러그인으로 결과 저장 → 사이트 표시.

## 운영에 적용할 변경

- `migration.sql`: 작업 대기열과 연결 상태용 테이블 2개, 요청 감지 트리거, 내부 큐 함수, 토큰 인증 RPC를 추가한다. 테이블에 RLS를 활성화한다. RPC는 작업 가져오기·완료 상태·연결 상태 확인만 제공하며 Agency 콘텐츠를 임의로 읽고 쓰는 기능은 없다. 별도의 긴 비밀 토큰을 검증하고 DB에는 해시만 저장한다.
- `queue-function.ts`: 기존 Agency 서버 함수 9개를 요청 저장용으로 전환한다. Claude/Gemini 모델 호출을 제거한다. 기존 사용자 인증과 내부 예약 인증을 검사한다.
- `cutover.sql`: 기존 예약 작업을 Codex 대기열로 전환한다. 사무실 출퇴근 예약은 유지하고 자동 아침 회의 중지와 야간 off 설정을 존중한다.
- `worker.py`, `install.py`: 이 Mac에 로그인한 사용자 세션에서 요청을 확인하고 Codex를 한 번에 하나 실행한다. 대기 중에는 모델을 호출하지 않는다. 운영 연결을 검증한 뒤 LaunchAgent를 설치한다.
- `agency.html`: 요청을 즉시 완료한 것처럼 표시하지 않고 대기 상태와 Codex 연결 상태를 표시한다.

## 검증과 전환 순서

로컬 테스트 → 명시적 운영 변경 승인 → DB 구조 추가·토큰 연결 → 읽기 전용 Codex 작업 검증 → 서버 함수와 예약 전환 → 사이트 반영 → 실제 요청 결과 재조회 → Claude 루틴 중지.

DB 적용 전이라 운영 SQL과 실제 사이트 요청의 통합 검증은 아직 할 수 없다. 자동 승인 검토가 이 영구적인 운영 DB 변경의 구체적인 사용자 승인을 요구해 적용을 차단했다.

잠금 화면에서도 컴퓨터가 깨어 있고 로그인 세션이 유지되면 CLI 작업은 실행할 수 있다. 잠자기·종료·로그아웃·네트워크 단절 시 요청은 대기한다. 브라우저 화면 조작이 필요한 일부 작업은 잠금 해제가 필요할 수 있다. ChatGPT 사용 한도와 연결 도구의 권한이 적용된다.

## 복구

기존 서버 함수·DB 함수·운영 지침은 비공개 `backups/`에 보존한다. 전환 문제가 있으면 작업 실행을 중지하고 기존 함수를 복구한 뒤 실행 제공자를 되돌린다. 기존 요청과 결과 데이터는 삭제하지 않는다. 토큰·실행 로그·백업은 Git에서 제외한다.

검증 명령: `python3 -m unittest -v test_worker.py` (이 폴더에서 실행).
