# 편집스크립트 HTML 테스트

공개 페이지: `/editing-script.html`. Google 연결 설정은 강의노트의 공개 OAuth Client ID를 공유합니다. 토큰은 메모리에서만 유지됩니다.

현재 동작: Google Slides PPT 목록/본문 읽기 → 공개 Dropbox 영상 링크를 강의별로 연결 → RT가 포함된 JSON/SRT/VTT 전사 가져오기 → 후보 자막/PPT 대응 구성 → 행별 검수 → 새 Google Sheet 생성 및 값 재조회 검증. 원본 PPT/기존 시트를 쓰거나 덮어쓰지 않습니다.

현재 미연결: Dropbox 폴더 자동 탐색, 영상 다운로드/오디오 추출, ASR 작업기. 링크만으로 자동 전사를 실행하지 않습니다. 공개 링크 접근에 Dropbox 로그인이 필요하지 않으며, Google 로그인은 Drive 읽기/저장에 필요합니다. 로컬 미디어는 브라우저에서 재생만 하고 업로드하지 않습니다.

자막/PPT 대응은 문자 유사도 기반의 검수 초안입니다. 음성 판독이나 재촬영 사용 여부를 확정하지 않습니다. 말꼬임·제작 대화도 원문에 보존합니다. 검수 JSON을 내려받아 보관할 수 있으며 세션 종료 시 편집은 사라집니다.

추후 작업기: PPT ID + 공개 영상 파일 링크를 작업 단위로 수신하고, 원본 RT를 유지하는 전사 segments를 반환해야 합니다. 브라우저에 API 비밀키를 넣지 않습니다. 저장 경로 기본값은 강의 폴더의 편집스크립트 폴더이며 직접 지정도 가능합니다.

검증: `node --test editing-script/test/*.test.mjs`

## Codex 작업요청
PPT 폴더 또는 상위 강의 폴더 입력 시 같은 상위 폴더의 `MP3`(`엠피쓰리`) 폴더를 읽습니다. 파일명 또는 명시적인 강의 번호가 유일하게 일치할 때 연결하고, 중복/미일치는 선택 UI로 확인합니다. 하나의 MP3가 여러 PPT에 연결되면 요청 생성을 차단합니다.

작업 요청 버튼은 팝업에 파일 IDs/링크와 기준을 생성합니다. 복사 성공 후 Slack에서 KWAN에게 전달하라는 안내가 표시됩니다. Slack 자동 전송이나 Codex 자동 실행은 하지 않습니다. OAuth 토큰은 요청에 포함하지 않습니다. 담당자에게 상위 폴더 편집 권한을 공유해야 합니다. 요청 생성만으로 Drive 파일을 만들거나 원본을 수정하지 않습니다.
