# 편집스크립트 HTML 테스트

공개 페이지: `/editing-script.html`. Google 연결 설정은 강의노트의 공개 OAuth Client ID를 공유합니다. 토큰은 메모리에서만 유지됩니다.

현재 동작: Google Slides PPT 목록/본문 읽기 → 공개 Dropbox 영상 링크를 강의별로 연결 → RT가 포함된 JSON/SRT/VTT 전사 가져오기 → 후보 자막/PPT 대응 구성 → 행별 검수 → 새 Google Sheet 생성 및 값 재조회 검증. 원본 PPT/기존 시트를 쓰거나 덮어쓰지 않습니다.

현재 미연결: Dropbox 폴더 자동 탐색, 영상 다운로드/오디오 추출, ASR 작업기. 링크만으로 자동 전사를 실행하지 않습니다. 공개 링크 접근에 Dropbox 로그인이 필요하지 않으며, Google 로그인은 Drive 읽기/저장에 필요합니다. 로컬 미디어는 브라우저에서 재생만 하고 업로드하지 않습니다.

자막/PPT 대응은 문자 유사도 기반의 검수 초안입니다. 음성 판독이나 재촬영 사용 여부를 확정하지 않습니다. 말꼬임·제작 대화도 원문에 보존합니다. 검수 JSON을 내려받아 보관할 수 있으며 세션 종료 시 편집은 사라집니다.

추후 작업기: PPT ID + 공개 영상 파일 링크를 작업 단위로 수신하고, 원본 RT를 유지하는 전사 segments를 반환해야 합니다. 브라우저에 API 비밀키를 넣지 않습니다. 저장 경로 기본값은 강의 폴더의 편집스크립트 폴더이며 직접 지정도 가능합니다.

검증: `node --test editing-script/test/*.test.mjs`

## Codex 작업요청
PPT 폴더 또는 상위 강의 폴더 입력 시 같은 상위 폴더의 `MP3`(`엠피쓰리`) 폴더를 읽습니다. 파일명 또는 명시적인 강의 번호가 유일하게 일치할 때 연결하고, 중복/미일치는 선택 UI로 확인합니다. 하나의 MP3가 여러 PPT에 연결되면 요청 생성을 차단합니다.

작업 요청 버튼은 팝업에 파일 IDs/링크와 기준을 생성합니다. 복사 성공 후 Slack에서 KWAN에게 전달하라는 안내가 표시됩니다. Slack 자동 전송이나 Codex 자동 실행은 하지 않습니다. OAuth 토큰은 요청에 포함하지 않습니다. 담당자에게 상위 폴더 편집 권한을 공유해야 합니다. 요청 생성만으로 Drive 파일을 만들거나 원본을 수정하지 않습니다.

## 완성본 기준 업데이트 — 2026-10-15
`policy.mjs`가 작업요청의 공통 기준입니다. 기준 시트 `2강_표현1!A1:E58`의 A~E만 확인했습니다. F열은 참고·전사·출력에서 제외합니다. 강의별 원문은 공개 코드에 저장하지 않습니다.

- 기본 결과: 상단 5행 출처/메타정보, 6행 헤더, 7행부터 데이터. A~E 5개 열만 생성합니다.
- RT, 강의, 표현 번호/세부 구간/판정, 실제 풀 발화, 필요한 자막.
- 주제/Decode/Pro Tip/Example/Check-Up/정답 템플릿과 ⏵핵심 요약을 요청에 포함합니다.
- 앞 테이크가 완전해도 재촬영과 비교하고, 미사용은 취소선 + 자막 빈칸. 일반 설명/반복 해설/제작 대화/엔딩 인사는 자막을 비웁니다.
- 확인된 무발화 구간은 별도 행. 판독 불가를 추정하지 않습니다. 웹의 후보 초안은 검수 후 확정해야 하며, 시트 자막은 확정 행만 저장합니다.

## 폴더 개별 지정 — 2026-10-16
현재 화면은 PPT 폴더와 오디오 폴더를 각각 지정한다. 이전 설명의 상위 폴더 자동 탐색은 더 이상 사용하지 않는다. 폴더명·오디오 위치는 자유이며 MP3·WAV를 지원한다. PPT 파일 선택 시에는 같은 PPT 폴더 안의 파일만 함께 선택한다.
저장 기본 경로는 선택한 PPT 폴더의 바로 위 상위 폴더 / 편집스크립트이며, 요청 JSON에도 이 상위 폴더 ID와 오디오 링크를 기록한다. 폴더는 실제 결과를 저장할 때만 생성·재사용하며 연결·요청 생성 단계에는 쓰지 않는다. 저장 전 PPT 폴더의 부모가 바뀌면 재연결을 요구한다.
Google 연결은 같은 탭에서 유효한 토큰을 복원하며, 만료 또는 연결 해제 시 지운다. 전사는 여전히 KWAN에게 요청 전달 후 처리한다.

## 강의·표현별 구조 및 폴더 경로 — 2026-10-16
PPT 폴더의 날짜별 하위 폴더를 함께 탐색한다. PPT 안의 표현1·표현2 구분을 읽고 day1-1.mp3 / day1-2.wav처럼 강의·표현 번호로 연결한다. 중복·누락·표현 구분 불명확은 확인 대상으로 남기며 목록에서 참고 PPT/표현을 작업 제외할 수 있다. 실제 요청/결과는 강의별 파일 하나 안에 표현별 탭을 만들고 각 RT를 해당 원본 오디오 00:00 기준으로 유지한다. 직접 검수 저장은 현재 강의에서 포함한 표현 전체의 결과가 준비되어야 한다.
PPT 링크를 입력하거나 Drive에서 고른 뒤 오디오 선택창을 열면 선택 PPT 폴더의 바로 위 상위 폴더부터 연다. 팝업 상단은 실제 접근 가능한 조상 폴더 경로를 표시하며 중간 폴더 클릭과 검색 폴더 진입을 지원한다. 권한으로 조상을 읽을 수 없는 경우 접근 가능한 위치까지만 표시한다.

### 하위 폴더·작업 제외 확인 — 2026-10-16
PPT·오디오의 모든 하위 폴더를 순환 방지와 폴더/파일 수 제한을 두고 탐색한다. 오디오와 유일하게 연결된 표현은 선택하고, 오디오가 없는 표현과 강의 번호 없는 참고자료는 작업 제외로 표시한다. 이번 사용자 자료의 오디오 부재는 기존 작업 완료 때문이라는 설명을 반영했으나, 코드가 누락을 완료로 기록하거나 기존 원장을 변경하지는 않는다. 중복 후보는 사람 선택 전 요청을 차단한다. 실제 복사본 25개 강의 PPT와 24개 음원 모두 대응 검증.


상위 폴더 하나를 선택하면 PPT·MP3/WAV를 모든 하위 폴더에서 찾는다. 오디오 별도 입력은 선택이다. 강의 묶음의 폴더 ID와 경로를 우선 비교하고, 별도 PPT/오디오 루트는 동일한 하위 강의 폴더 이름으로 대응한다. 같은 1강·18강도 서로 다른 강의 묶음의 음원을 가져오지 않는다. 모호한 경로·중복 음원은 직접 선택이 필요하다. 요청 JSON은 group/sourceFolderPath를 보존한다.
